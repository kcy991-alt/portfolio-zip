## 4. 이렇게 써요 (How it works)

### 경험 기록부터 포트폴리오 완성까지, 단 3단계

- **STEP 01. 프로젝트가 끝나면 바로 기록해요.** 기억이 선명할 때 프로젝트 이름, 역할, 문제만 먼저 적어도 괜찮아요.
- **STEP 02. 10단계 질문을 따라 경험을 구체화해요.** 질문과 예시를 참고해 차근차근 작성해요. 지금 기억나지 않는 내용은 나중에 채워도 돼요.
  - (2026-10-13 추가) STEP 02 카드 안에 강조 박스: **✨ 기획서가 있다면, AI로 초안부터** — 내 AI에 기획서와 제공된 프롬프트를 보내고, 결과를 붙여넣으면 초안이 완성돼요. (별도 카드·비교표 줄은 두지 않는다. portfolio_zip이 문서를 읽는 것처럼 쓰지 않는다.)
- **STEP 03. 필요한 프로젝트를 골라 포트폴리오로 만들어요.** 지원할 프로젝트를 골라 하나로 묶고, PDF로 저장해요. *(PDF 저장은 컴퓨터에서 하는 것을 권장해요.)*

## 5. 신뢰 (Credibility) — 앵커 `#steps`

### 무엇을 써야 할지 고민하지 않도록, 질문부터 준비했어요.

9년 차 PM의 작성 방식과 한국PM협회가 주관하는 PSC 자료실의 ‘PM 포트폴리오 템플릿’을 참고해, 경험을 구체화하는 10단계 질문으로 만들었어요. *("참고한 자료 보기" 링크는 2026-10-08 사용자 요청으로 삭제. 참고 자료 주소: https://psc-exam-dgzt.vercel.app/resources/pm-portfolio-template)*

**10단계 칩:** 개요 → 역할 → 문제 정의 → 근거 → 인사이트 → 가설 → 해결안 → 성공 지표 → 실행 → 회고

확인 사항: 해당 페이지에는 "한국PM협회가 작성했다"는 문구가 없고 푸터에 "주관 한국 PM협회", 운영 사업자는 파이로 소프트로 적혀 있다. 그래서 "추천했다·게시했다"가 아니라 "주관하는 자료실의 템플릿을 참고했다"로 쓴다. 이 문장이 사실이어야 하고(실제로 참고했는가), 협회 이름 사용에 문제가 없는지 공개 전에 확인한다.
