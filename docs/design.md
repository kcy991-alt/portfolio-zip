# 디자인

Google Stitch 시안(`stitch_portfolio_zip_web_app`, 화면 15개 + `DESIGN.md`)에서 spec.md 범위에 맞는 것만 채택했다. 시안 원본은 바탕화면의 `stitch_portfolio_zip_web_app (1)` 폴더에 있다. 브랜드·로고는 아직 확정되지 않았다(spec 19장).

## 컨셉

내 경험을 파일로 쌓고, 필요한 파일을 묶어 포트폴리오를 만든다. 차분한 권위감, 넉넉한 여백, 평평한 면 위에 옅은 테두리와 그림자. 장식은 넣지 않고, 모든 카드는 맥락·소유·시간 중 하나를 나타낸다. 운영체제 흉내, 터미널 UI, 불필요한 애니메이션은 쓰지 않는다.

## 컴포넌트 규칙

- **버튼**: 기본(파랑 배경·흰 글씨, 높이 44px, 모바일 48px), 보조(옅은 파랑 배경·파란 글씨), 고스트(투명·회색 글씨·테두리).
- **입력**: 높이 44px, 포커스 시 파란 테두리와 15% 파란 후광. 라벨은 항상 보이고 placeholder는 회색 예시일 뿐이다.
- **칩·태그**: 높이 24px. 기본은 회색 바탕, 선택은 옅은 파랑 바탕.
- **체크박스**: 18px, 선택 시 파란 배경과 흰 체크.

## 시안에서 제외한 것 (spec 범위 밖이거나 근거 없음)

시안에 있었지만 앱에는 넣지 않는다. 다시 넣을 때는 spec을 먼저 바꾼다.

- **기능**: 카카오 로그인, SSO, 2단계 인증, 이메일·비밀번호 로그인(Google 로그인만 사용), 요금제(Pro/Standard)와 업그레이드, 프로젝트 20개 한도, 공유 링크("발표용 링크 공유"), ZIP 아카이브 내보내기, "내용 줄이기(AI 요약)", 슬라이드 테마(미니멀 블루 등), 프로필 사진 업로드, 템플릿 추천(직무별 템플릿은 P2).
- **문구**: "엔터프라이즈급 256비트 암호화", "v2.4 보안 인증", "PM 채용 평균 열람 분량", "전달력 2배 향상", "합격 포트폴리오 가이드 매칭", "필수 입력 항목" 표시(작성을 강제하지 않는다).
- **용어**: "슬라이드"는 쓰지 않고 "페이지"로 쓴다. "내보내기" 대신 "PDF로 저장하기"(브라우저 인쇄).
- **샘플 내용**: 실제 회사 이름, 지어낸 성과 수치(퍼센트·금액)는 쓰지 않는다. 샘플은 가상 내용이고 "샘플"이라고 표시한다.
- **시안 잔재**: "다이얼로그 프리뷰 스튜디오", "상태 전환" 탭, "폴더 삭제 테스트", "Neo-Fintech Mode", 깨진 로고 이미지.

## 시작 화면 구성

검은 히어로(제목, "바로 시작하기" 버튼, 보관함 미리보기 카드) → 흰 배경 "모두를 위한 정리" 카드 3개 → 옅은 파랑 배경 "쓰면서 바로 결과를 확인해요"(편집·미리보기 목업) → 번갈아 배치된 기능 3줄(수치가 없어도 괜찮아요 / 내가 한 일을 분명하게 / 원본은 그대로, 제출용은 따로) → 검은 "내 경험은 나만 볼 수 있어요" 섹션 → 마무리 CTA → 푸터. "바로 시작하기" 버튼은 상단 바와 히어로, 마무리 구간에 둔다. 신뢰 섹션에는 spec에 있는 사실만 쓴다(기본 비공개, 휴지통 30일 보관, 계정 삭제 요청).

## 로그인 없이 써 보기 (spec F15)

- 시작 화면의 "바로 시작하기" → 첫 방문 안내(`/welcome`) → 보관함(`/workspace`) 순서로 로그인 없이 들어온다. 로그인한 사용자와 **같은 화면**이고 샘플 데이터는 없다(빈 보관함에서 시작).
- 보관함 맨 위에 안내가 붙는다: "로그인하지 않았어요. 지금 만든 폴더와 프로젝트는 이 화면에서만 써 볼 수 있고 저장되지 않아요. 새로고침하거나 창을 닫으면 사라져요. 저장하려면 로그인하세요."
- 사이드바 아래: 로그인 전에는 "로그인 없이 써 보는 중 · 저장되지 않아요" + "로그인하고 저장하기" 링크, 로그인 후에는 이메일과 로그아웃.
- 편집 화면 상단 상태 칩: 로그인 전 "저장되지 않음 · 로그인하면 저장돼요" + "저장" 버튼, 로그인 후 "저장 대기 중 → 저장 중 → 저장됨"(실패하면 "저장 실패 · 다시 시도"와 이유).
- **"저장" 버튼**을 누르면 가운데 창이 열린다: 제목 "저장하려면 로그인이 필요해요", 이유 한 줄, "지금 만든 내용은 저장되지 않아서 로그인 과정에서 사라져요. 로그인 없이 계속 써 보는 것도 괜찮아요.", 기본 버튼 "Google로 로그인"(파랑), 보조 버튼 "계속 써 보기". Esc와 바깥 클릭으로 닫히고, 열리면 "Google로 로그인"에 포커스가 간다.
- 체험 중에 만든 프로젝트의 주소를 새로고침 뒤에 열면 "체험 중에 만든 프로젝트는 새로고침하면 사라져요" 안내와 "프로젝트 아카이브로" 버튼이 나온다.
## 휴지통 (spec F13, S08)

- 위치: 사이드바 "휴지통 · 30일 보관" 링크, 주소 `/workspace/trash`.
- 구성: 제목과 "삭제한 항목은 30일 동안 보관하고, 그 뒤에는 자동으로 영구 삭제돼요." 설명, 종류 탭(전체·프로젝트·폴더, 개수 표시), 결과 메시지 줄(복원했어요 등, `aria-live`), 항목 목록.
- 항목 한 줄: 종류 칩, 이름, 프로젝트는 "원래 위치: 폴더 이름"(폴더가 삭제되었으면 "(삭제된 폴더)", 폴더가 없었으면 "미분류")과 삭제일, 남은 날수("N일 남음", 3일 이하는 빨간색 굵게, 당일은 "오늘 삭제됨"), 버튼 "복원"(보조 파랑)과 "영구 삭제"(빨강 텍스트).
- 영구 삭제는 확인 창에서 "영구 삭제하면 다시 복원할 수 없어요."를 빨간 글씨로 한 번 더 알린다. 프로젝트 삭제 창은 "휴지통에서 30일 동안 보관하고, 그 안에는 언제든 복원할 수 있어요."라고 안내한다.
- 비어 있으면 점선 상자에 "휴지통이 비어 있어요.". 불러오기에 실패하면 오류 문구와 "다시 시도".
- 로그인 전 체험 중에는 "로그인하지 않아서 이 휴지통도 저장되지 않아요. 새로고침하면 비워져요." 안내가 붙는다.
## 이미지 첨부 (spec F06, 7.5)

- 모든 질문 섹션 카드 아래에 구분선과 함께 "이미지" 자리가 있다. 프로젝트 개요 단계에는 그 위에 "대표 이미지" 자리가 하나 더 있다.
- 자리 구성: "+ 이미지 추가"(파랑 테두리 버튼, 올리는 동안 "올리는 중…"), 안내 "JPEG·PNG·WebP, 10MB 이하. 큰 이미지는 올리기 전에 자동으로 줄여요.", "이름·연락처·회사 내부 정보가 보이지 않는지 확인하고 올려 주세요.", 실패하면 빨간 문구 + "입력한 글은 그대로 있어요."
- 이미지 카드(좁은 화면에서는 세로, 넓으면 가로): 왼쪽에 미리보기(`contain`, 비율 유지, 잘라내지 않음), 오른쪽에 캡션, 대체텍스트(비어 있고 장식용이 아니면 빨간 안내), 체크 "장식용"·"출력에 포함", "구역" 선택, "↑ 앞으로"·"↓ 뒤로"·"삭제"(누르면 "이 이미지를 지울까요?" + 지우기/취소).
- 미리보기 페이지: 붙인 이미지가 해당 구역 안에 작게(높이 최대 약 96px) 나타나고, 캡션이 아래에 붙는다. 대표 이미지가 없으면 "아직 대표 이미지가 없어요."
- 로그인 전 체험에서는 "+ 이미지 추가"를 누르면 "이미지를 올리려면 로그인해야 해요" 안내가 뜬다.
## 포트폴리오 제작 (spec F09~F11, S04·S05)

- **목록(`/portfolios`)**: 제목 "포트폴리오 제작", "새 포트폴리오 만들기" 버튼(제목 80자), 행마다 제목·프로젝트 개수·수정일과 "삭제"(휴지통). 비어 있으면 "첫 포트폴리오를 만들어 보세요". 로그인 전에는 보관함과 같은 "저장되지 않아요" 안내가 위에 붙는다.
- **편집(`/portfolios/:id/edit`)**: 위에 제목 입력과 저장 상태(로그인 후 저장 대기 중→저장 중→저장됨, 실패 시 "다시 시도", 로그인 전 "저장되지 않음 · 로그인하면 저장돼요"), "미리보기·PDF 저장 (준비 중)" 비활성 버튼. 1,280px 이상은 3열: 왼쪽 페이지 구성(260px), 가운데 페이지 미리보기, 오른쪽 입력(360~440px). 미만은 "페이지 구성 / 입력 / 미리보기" 탭.
- **페이지 구성**: "기본 페이지"(표지, Summary·프로필은 "넣기" 체크), "프로젝트 (N)" 카드(제목, ↑↓ 순서 버튼, "원본 업데이트 있음" 표시, 소개·분석·실행·결과 버튼). 빼기로 정한 페이지는 글자가 흐리고 취소선이 그어진다. 맨 아래 "+ 프로젝트 추가".
- **입력 패널**: 표지(이름·지원 직무·한 줄 소개, 연락처 포함 스위치 기본 꺼짐, 이메일·링크), Summary(항목 카드: 제목·설명·연결 프로젝트 체크, 위/아래/삭제, 최대 5개일 때 추가 버튼이 사라짐), 프로필(소개, 교육·경력·도구 반복 카드), 프로젝트 사본(설명 "프로젝트 아카이브의 프로젝트를 복사한 거예요. 여기서 고쳐도 원본은 바뀌지 않아요.", 제목, 페이지 설정과 보일 섹션 체크, 단계별 내용 고치기, 이미지 선택, 사본 관리).
- **창**: 프로젝트 추가(체크 목록, 이미 담은 프로젝트는 "이미 N번 담음"), 원본에서 다시 가져오기(덮어쓰기 경고, 파란 확인), 이 제작본에서 빼기(원본은 남는다는 안내와 Summary 연결 해제 개수), 충돌 창(닫을 수 없음).
- **미리보기**: 표지(크게 이름·직무·소개, 연락처는 켰을 때만), Summary(항목 카드와 연결 프로젝트 칩), 프로필(소개·교육·경력·도구 칩, 빈 영역은 안내), 프로젝트 페이지(경험 편집 화면과 같은 구역 카드, 숨긴 섹션의 구역은 빠짐). 편집용이라 빈 자리 안내가 보이고 실제 출력(D5)에는 나오지 않는다.
## 지키는 규칙

- 구현되지 않은 기능은 비활성화하고 이유를 적는다. 저장된 것처럼 보이는 상태 표시는 쓰지 않는다.
- 저장되지 않는 화면(로그인 전 체험)은 저장되지 않는다는 점을 숨기지 않고 밝힌다.

## 사이드바·편집 화면 개선 (2026-10-13)
- 사이드바 접기: 1,280px 이상에서 로고 오른쪽 «로 접고, 접으면 왼쪽 위 »만 남는다. 선택은 이 브라우저에 기억한다(`localStorage`, 없어도 동작). 1,280px 미만은 기존 서랍형.
- 두 구역 제목(`프로젝트 아카이브`, `포트폴리오 만들기`)은 번호 원 + 테두리 + › 가 있는 버튼 모양으로 바꿨다. 누르면 그 구역 전체 화면으로 간다. 글자만 있어 제목처럼 보인다는 의견을 반영했다.
- 로고 바로 아래 안내 상자: "① 프로젝트 아카이브에서 경험을 정리하고, ② 포트폴리오 만들기에서 정리한 프로젝트로 포트폴리오를 만들어요."
- 사이드바에 `마이페이지` 링크(설정 위).
- 편집 화면: 단계 이름·진행 퍼센트(큰 숫자)·두꺼운 진행 바·단계 선택·미리보기를 오른쪽 한 카드에 모았다. 1,280px 미만이나 미리보기를 접었을 때는 머리말에 같은 묶음이 보인다. 진행 바는 `role="progressbar"`이고 퍼센트는 현재 단계의 위치다.
- 프로필: 자격증 카드(이름·발급 기관·취득일)를 경력 아래, 도구 위에 추가. 포트폴리오 프로필 맨 위에 "마이페이지에서 불러오기" 줄을 둔다.
- (같은 날 수정) 사이드바 폭을 240px에서 288px로 넓히고, 안내 문구는 단어 단위(`break-keep`)로 줄바꿈하며 번호 칸을 따로 둬 둘째 줄이 글자에 맞춰 들여쓰기 되게 했다.
- (같은 날 수정) 하위 메뉴는 항상 떠 있지 않고 구역 버튼을 눌렀을 때만 펼쳐진다. ①을 누르면 폴더·프로젝트 트리, ②를 누르면 `내 포트폴리오`가 나온다. 지금 보고 있는 화면이 속한 구역은 기본으로 펼쳐지고, 같은 구역 버튼을 다시 누르면 접힌다. `휴지통`·`마이페이지`·`설정`은 항상 보인다. 버튼 오른쪽 `›`는 펼치면 아래로 돈다.
- (같은 날 수정) 사이드바 접기·펼치기 아이콘을 `«`·`»` 글자에서 패널 아이콘(사각형 왼쪽에 세로줄)으로 바꿨다.
- (같은 날 수정) 편집 화면 오른쪽 카드에서 "모든 질문에 답하지 않아도 괜찮아요. 퍼센트는 지금 위치이고, 점수가 아니에요." 문구를 뺐다. 미리보기 머리줄은 좁으면(사이드바를 연 상태) 제목 아래 줄로 `이전 · 페이지 · 다음`이 내려가고, 제목은 단어 단위로 줄바꿈하며 버튼 글자는 꺾이지 않는다.
